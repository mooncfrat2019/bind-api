=== Initial Setup ===

1. Get your bootstrap API key:
   kubectl get secret -n {{ .Release.Namespace }} {{ include "bind-api.fullname" . }}-secrets -o jsonpath='{.data.BIND_API_BOOTSTRAP_KEY}' | base64 -d

2. Create your first API key:
   curl -X POST "<API_URL>/api/keys" \
     -H "Content-Type: application/json" \
     -H "X-API-Key: <BOOTSTRAP_KEY>" \
     -d '{"name":"admin","permissions":["*"],"expiresIn":8760}'

3. IMPORTANT: Revoke the bootstrap key after creating your permanent key!

=== Next Steps ===

1. Create your first DNS zone:
   curl -X POST "<API_URL>/api/write/zone" \
     -H "Content-Type: application/json" \
     -H "X-API-Key: <YOUR_API_KEY>" \
     -d '{"name":"example.com","email":"admin@example.com","nsIP":"192.168.1.10"}'

2. Add DNS records:
   curl -X POST "<API_URL>/api/write/zone/example.com/record" \
     -H "Content-Type: application/json" \
     -H "X-API-Key: <YOUR_API_KEY>" \
     -d '{"name":"www","type":"A","value":"192.168.1.100","ttl":3600}'

3. For replica deployment, install with values.replica.yaml:
   helm install bind-api-replica ./bind-api -f values.replica.yaml
